# Nutri Bazaar – Dry Fruits Shop

A colourful single-page dry fruits shop.

## Features
- Browse dry fruits (almonds, cashews, pistachios, dates, figs and more)
- Choose 250 g, 500 g or 1 kg packs
- Cart with quantity change and remove
- Demo checkout with delivery details
- Add and delete shop items with "Manage items"
- Saves items and cart in the browser

## How to run
Open index.html in any browser.

## Tech
HTML, CSS, JavaScript (no frameworks)

## Note
Checkout is a demo. No real payments are taken.
